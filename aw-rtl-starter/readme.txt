AW RTL Starter - README
-----------------------

معلومات سريعة:
- قالب بسيط وجاهز للعربية (RTL).
- يحتوي على: هيرو قابل للتخصيص (Customizer)، خدمات (CPT)، بورتفوليو (CPT)، قسم المقالات، نموذج تواصل بإرسال عبر wp_mail (AJAX).

كيفية التثبيت:
1. أنشئ مجلدًا جديدًا باسم aw-rtl-starter.
2. احفظ كل الملفات المدرجة هنا داخل ذلك المجلد مع الاحتفاظ ببنية المجلد assets/js/main.js.
3. اجعل الترميز UTF-8.
4. اضغط المجلد إلى ZIP:
   - على لينكس/ماك: zip -r aw-rtl-starter.zip aw-rtl-starter
   - على ويندوز: حدد المجلد -> Send to -> Compressed (zipped) folder
5. لوحة ووردبريس: المظهر → قوالب → أضف جديد → رفع قالب → اختر aw-rtl-starter.zip → تثبيت وتفعيل.

ملاحظات مهمة:
- نموذج التواصل يستخدم wp_mail؛ لضمان وصول الرسائل يفضّل إعداد SMTP عبر إضافة مثل WP Mail SMTP.
- لإضافة "خدمات" و "أعمال" استخدم لوحة التحكم → خدمات (Services) / أعمال (Portfolio) لإضافة عناصر. عين الصورة البارزة لكل عنصر ليظهر في الشبكات.
- لتعديل عنوان الهيرو، نصه، الزر والرابط، والصورة: اذهب إلى المظهر → تخصيص → Hero.
- لإضافة صفحة "من نحن" ضع صفحة slug باسم "about" أو استخدم محرر الصفحة الرئيسية.
- لتحسين الأداء استخدم إضافة Caching وImage optimization.
